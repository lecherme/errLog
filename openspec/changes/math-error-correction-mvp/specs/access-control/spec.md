## Purpose

确保所有学习数据仅对经过认证的用户可访问，MVP 支持家庭单账号使用场景，不实现完整 SaaS 账号体系。

## ADDED Requirements

### Requirement: 未认证用户不能访问任何受保护资源
系统 SHALL 拒绝未经认证的请求访问任何数据，包括但不限于：原始 PDF、批改照片、错题记录、知识点标签、订正卷。

#### Scenario: 未登录用户访问受保护页面
- **WHEN** 未认证用户尝试访问任意受保护页面或数据接口
- **THEN** 系统拒绝访问并引导用户进行身份认证，不返回任何业务数据

### Requirement: 已认证用户可访问其自身账号归属的资源
当请求已通过身份认证、且请求的资源归属于发起请求的 User 本身，或归属于该 User 账号下其有权访问的 Child，且该资源所属 capability 自行定义的其他访问前置条件（如资源自身的存在性、状态等）也已满足时，系统 SHALL 允许该访问，SHALL NOT 仍以"未认证"为由拒绝。已通过身份认证 SHALL NOT 单独构成访问归属于其他 User 账号的资源的授权。

#### Scenario: 认证后可访问自身账号归属且前置条件已满足的资源
- **WHEN** 用户完成身份认证，请求访问归属于自身账号（或其账号下有权访问的 Child）、且该资源自身其他访问前置条件已满足的卷子档案、批改任务或错题记录
- **THEN** 系统允许访问，不因缺少认证而拒绝

#### Scenario: 已认证用户不能访问其他账号归属的资源
- **WHEN** 已认证用户请求访问归属于另一个 User 账号的 WorksheetArchive、GradingSession 或 ErrorQuestion
- **THEN** 系统拒绝该访问，即使请求本身已通过身份认证

### Requirement: MVP 为家庭单账号使用场景
MVP SHALL 支持单一账号的家庭使用场景，SHALL NOT 要求实现用户注册、邀请、密码找回或角色权限管理功能。

#### Scenario: 无需注册流程即可使用
- **WHEN** 家庭首次部署并配置应用
- **THEN** 家长可直接使用预设的认证方式访问，无需经过公开注册流程
