## Safe commits

`tools/safe-commit.mjs` is a task-agnostic commit/push executor for any harness,
including future tools such as Superflowers. The harness supplies an exact file list
and commit message; the script checks policy, creates a reviewable plan, commits only
the approved Git content, and returns stable process and symbolic error codes. It has
no OpenSpec dependency. See [the safe-commit protocol](docs/safe-commit.md) for the
request schema and integration flow.

## OpenSpec setup

The standard Claude Code commands and skills under `.claude/` are generated locally
and are intentionally not committed. After cloning the repository, install the pinned
OpenSpec version and initialize the Claude integration:

```bash
# Requires Node.js 20.19 or newer.
npm install -g @fission-ai/openspec@1.10.0
openspec --version
openspec init --tools claude --profile core
```

The repository does track its project-specific OpenSpec content:

- `openspec/config.yaml`
- `openspec/specs/**`
- `openspec/changes/**`, including each change's `scratchpad.md`
- `.claude/commands/opsx/refine.md`
- `.claude/skills/openspec-refine-change/SKILL.md`

The two `refine` files are repository-owned customizations and are not generated by
OpenSpec 1.10.0. Review them explicitly before upgrading OpenSpec or switching workflow
profiles, because a future OpenSpec release may introduce a conflicting workflow.
